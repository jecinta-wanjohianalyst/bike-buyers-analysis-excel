# Bike Buyers Analysis Using Excel

## Project Overview

This project explores customer data to understand the characteristics and purchasing behaviour of bike buyers using Microsoft Excel.

The project is part of my data analytics learning journey, where I am building practical skills in data preparation, analysis, and visualization.

## Objectives

- Explore customer demographics and purchasing patterns.
- Examine variables such as age, income, and other customer characteristics.
- Use Excel tools to summarize and interpret customer data.
- Present findings in a format that supports business decision-making.

## Tools Used

- Microsoft Excel
- Data cleaning and preparation
- Pivot tables
- Charts and data visualization
- Excel dashboarding

## Project Workflow

1. **Data preparation:** Review and prepare the dataset for analysis.
2. **Data exploration:** Examine customer characteristics and purchasing behaviour.
3. **Data analysis:** Summarize relevant variables using Excel analysis tools.
4. **Visualization:** Use charts and dashboard elements to communicate findings.

## Key Learnings

This project helped me practise working with structured data in Excel and develop my understanding of how customer data can support business analysis.

## Files Included

- `Excel Project Dataset.xlsx` — Excel workbook containing the project data and analysis.
